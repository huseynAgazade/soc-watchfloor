# Prototype — approved UI reference

`portal.html` is the **approved** static prototype of the whole portal: every
view, the two-team rotas, SLA-by-severity, MITRE coverage, the rule inventory,
the admin query catalog, and the theme system. It is a single self-contained
file — open it in a browser, no build step.

It is the **source of visual truth** the `apps/web` Next.js app is built to
match. When a screen's behaviour is in question, this file is the answer. It
uses mock data shaped exactly like the real tool outputs.
